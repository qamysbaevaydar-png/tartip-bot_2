# TARTIP Course Bot V2

28 күндік TARTIP курсы үшін Telegram бот. V1-ден өзгерістер төменде жазылған.

## V2-де не жаңа

- **Access system**: бот жабық каналда мүше екенін автоматты тексереді. Каналда жоқ адам тіркеле алмайды.
- **Бөлек меню**: сен (админ) ботты ашқанда қосымша командалар көресің, қарапайым клиент оларды көрмейді.
- **`/lessons`** — 26 видео сабақтың каталогы, клиент өзі қалағанын таңдап көреді.
- **`/progress`** — клиент өз прогресін көреді (визуалды жолақпен).
- **`/support`** — клиент саған тікелей хабарласа алады.
- **`/admin`** — 🟢 қалыпты / 🟡 назар керек / 🔴 араласу керек деп клиенттерді автоматты жіктейтін панель.
- **`/pause`, `/resume`, `/reset`** — клиентті тоқтату, қайта қосу, прогресін нөлдеу.
- **Streak сөзі жеңілдетілді**: "5 күн тоқтаусыз" (ағылшын сөзі жоқ).
- **XP/Level алынып тасталды** — қарапайым, түсінікті көрініс қалды.
- **28 күндік тапсырмалар** (`tasks.json`) — өзгертілмеді, бұрынғы қалпында.

## 1-қадам: Ботты каналға админ ету (Access system үшін міндетті)

Access system жұмыс істеуі үшін бот сенің жабық каналыңда **админ** болуы керек:

1. Жабық каналыңды аш → **Мүшелер** (Participants/Administrators)
2. **"Добавить администратора"** бас
3. Ботыңды тап (@tartip_course_bot), қос
4. Құқықтарында кемінде **"Мүшелерді көру"** қосулы болуы керек (әдепкі бойынша қосулы келеді)

## 2-қадам: Канал ID-ін табу

1. Каналда кез келген хабарлама жаз
2. Сол хабарламаны **@RawDataBot** немесе **@userinfobot**-қа forward жаса
3. Ол саған каналдың ID-ін қайтарады (мыс: `-1003762687569`)
4. Осы санды `.env` файлындағы `CHANNEL_ID` өрісіне қой

**Ескерту:** `CHANNEL_ID` бос қалса, access system өшірулі болады — кез келген адам ботты тауып, тіркеле алады (V1-дегідей).

## 3-қадам: Орнату (V1-мен бірдей)

1. `.env.example`-ды `.env` деп көшір
2. Ішіне толтыр: `BOT_TOKEN`, `ADMIN_IDS`, `CHANNEL_ID`
3. Компьютерде сынау:
   ```
   pip install -r requirements.txt
   python bot.py
   ```

## 4-қадам: Railway-ге қою (24/7 жұмыс үшін)

V1 README-де жазылғандай:
1. GitHub-қа файлдарды жүкте (`tartip.db`-ні қоспа — ол автоматты жасалады)
2. railway.app-та "Deploy from GitHub repo"
3. Variables бөлімінде `.env`-дегі бәрін қос
4. **МІНДЕТТІ: Volume қос** (Settings → Volumes → "New Volume", mount path: `/app` немесе жоба түбірі) — әйтпесе әр жаңартуда клиенттер деректері өшіп кетеді

```json
"27": {"title": "🎯 Жаңа тақырып", "link": "https://t.me/c/.../XX"}
```

## Клиенттерді басқару (админ командалары)

- `/admin` — жалпы көрініс (қанша 🟢🟡🔴)
- `/problems` — 🟡🔴 клиенттердің толық тізімі (аты, ID)
- `/user 123456` — бір клиенттің толық профилі
- `/pause 123456` — клиентке тапсырма жіберуді тоқтату (демалыс кезінде)
- `/resume 123456` — қайта қосу
- `/reset 123456` — клиентті 1-күнге қайтару (курсты қайта бастаса)
- `/broadcast Хабарлама мәтіні` — барлық активті клиентке жіберу
