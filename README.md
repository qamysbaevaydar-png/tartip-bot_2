# TARTIP Course Bot V4

Telegram бот: 5 бағыт × 28 күн. Мақсат — клиент 28 күнде өз жүйесін құрып, ботсыз жалғастыра алатын болсын.

Бағыттар: Арықтау · Салмақ қосу · Бұлшық ет өсіру · Дисциплина · Ұйқы мен энергия.
Шеңбер: 1-апта Түсіну → 2-апта Әрекет → 3-апта Тұрақтылық → 4-апта Өзіндік басқару.

## Не істейді
- Тіркеуде қысқа анкета: ояну/жату уақыты, ас саны, жаттығу орны, шектеулер, денсаулық белгісі, 18+.
  Миссиялар осы уақытқа сай жеке құрылады (астар, экранды өшіру, серуен уақыты).
- Күн сайын бір нақты миссия: жоспар, есеп форматы, 2–10 минуттық «қиын күн нұсқасы».
- Батырмалар: ✅ Орындадым · ⚡ Жеңіл нұсқа · ↩️ Кешегіні жабу · 🛟 Жоспар B · 💬 Кураторға жазу.
- Жауаптар «Менің жүйем» құжатына жиналады (`/system`); 28-күні толық құжат беріледі.
- Апталық review: жауап бөлек сақталады, орындалуға қарай келесі аптаға бейімделу ұсынысы беріледі.
- Дауыстық жауап қабылданады.
- `/support` админге жетеді; админ карточкадан бірден жауап жаза алады.
- `/forget` растаумен барлық деректі өшіреді.

## Админ (`/admin`)
Назар керек / Жаңа / Барлық клиент каталогы. Клиент картасында: профиль, мақсат, осы аптадағы орындалу (x/7),
қатарынан күн, соңғы жауаптары, ✉️ хабар жазу, 📨 апталық қорытынды жобасы, пауза, растаумен нөлдеу.
Күн сайын 10:30-да админге «кімге назар керек» дайджесті келеді.
Күйлер: 🟢 бүгін орындады · ⚪ күн жүріп жатыр · 🟡 кеше өткізді / кешке дейін жасамады · 🔴 2+ күн өткізді.

## Іске қосу
```
pip install -r requirements.txt
cp .env.example .env     # BOT_TOKEN, ADMIN_IDS, CHANNEL_ID толтыр
python bot.py
```
Дерекқорды сақтау үшін хостингте Volume қосып, `DB_PATH=/data/tartip.db` қой (әйтпесе әр деплойда дерек жоғалады).

## GitHub-қа жүктеу
1. `.env` және `*.db` GitHub-қа ЖҮКТЕЛМЕЙДІ (`.gitignore`-да бар). Токенді тек хостингтің Variables бөліміне қой.
2. Ескі репода бұрын `.env`/`tartip.db` жүктеген болсаң, BotFather-де токенді жаңарт (Revoke) және `CHANNEL_ID`-ді тексер.
3. Файлдарды ауыстыр: `bot.py`, `database.py`, `plan.py`, `programs.json`, `categories.json`, `README.md`, `.env.example`, `.gitignore`, `tests/`.
   `tasks.json` енді қолданылмайды, жоюға болады.
4. Ескі дерекқор бар болса, бірінші іске қосуда автоматты көшіріледі (бұрынғы клиенттер мен тарих сақталады).

## Тексеру
```
python tests/test_core.py
python tests/test_bot.py
```
Бұл тесттер логиканы жалған Telegram нысандарымен тексереді. Нақты Telegram-да ойнау үшін `BOT_TOKEN` керек.

## Файлдар
`bot.py` — Telegram логикасы · `plan.py` — уақыт есептеу, миссияны бейімдеу, жүйе құжаты · `database.py` — SQLite ·
`programs.json` — 140 миссия · `categories.json` — бағыттар · `lessons.json` — видео сабақтар.
